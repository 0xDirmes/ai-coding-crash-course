What is Cadence?

The product you'll be building features for, explained without any code.

Cadence is a website for selling and taking online courses. Think of a small Udemy. Instructors put courses up, students pay for them and work through them, and admins keep the place tidy.

It's the practice project for Matt Pocock's AI Coding Crash Course. It's built to feel like a real product with real rough edges, so adding features to it feels like real work.

Courses belong to a category (Programming, Design, Data Science…) and have a status: draft (instructor still working on it), published (visible and buyable) or archived.

A student's journey

  1. Browse the catalog and open a course page with its description and syllabus.
  2. Buy it. There's no real payment provider: clicking "confirm" records the purchase and enrolls you.
  3. Learn: watch each lesson's video, read its content, pass its quiz. Progress is tracked per lesson.
  4. Dashboard shows courses in progress and completed.

The money side (your corner)

  • Prices are stored in cents, so 4999 means $49.99.
  • Pricing by country (PPP). The price drops by 30%, 50% or 70% depending on where the buyer is. For example, a $49.99 course costs $25.00 from India. Instructors can switch this off per course. A discounted purchase is locked to the country it was bought in.
  • Team purchases. A company buys N seats and gets N coupon codes. Employees redeem a code at /redeem/<code> to get access. The buyer manages codes on the Team page.

Quirks of a practice app

  • No passwords. Login is by email only, and a dev panel lets you switch between any seeded user instantly.
  • The dev panel can also fake your country, so you can watch PPP prices change.
  • No real payments. Stripe integration is one of the features on the to-do list.

Try it (5 minutes)

  1. In the terminal: npm install && npm run db:migrate && npm run db:seed && npm run dev
  2. Open localhost:5173. Use the dev panel to become Emma Wilson (student) and buy a course.
  3. Switch the dev country to India and look at another course's price.
  4. Become Sarah Chen (instructor) and open one of her courses in the instructor area.
