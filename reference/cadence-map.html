Conventions

  • Money is integer cents. Format only at display time (formatPrice).
  • Prices are server-authoritative. Actions recompute them; forms send an intent.
  • Actions parse input with a Zod schema, often a discriminatedUnion("intent", …).
  • Control flow: throw redirect(...), throw data(msg, { status }).
  • Services use positional params and synchronous Drizzle (.get() .all() .run()).
  • Auth: getCurrentUserId(request), where null means logged out. Dev users are switched via the DevUI panel.
  • Tests: vi.mock("~/db", () => ({ get db() { return testDb; } })) + createTestDb() + seedBaseData().

Known sharp edges (money paths)

  • createPurchase + enrollUser are not wrapped in a transaction (purchase route, lines 149–150).
  • PPP rounding is Math.round (half-up) on cents.
  • Team purchase stores the total (pppPrice × quantity) in one purchases row.
  • Country lookup silently falls back to null, which means tier 1 (full price).
